# 需求规格说明书（Requirements）

> 项目：企业级 RAG + Agent 智能知识库系统（smart-kb-agent）
> 产品定位：面向 HR / 行政 / 客服 的企业内部知识库问答助手
> 版本：V1（P0 + P1 已完成）

## 1. 项目定位

面向 20~200 人中小团队的 HR / 行政 / 客服，上传企业制度、FAQ、手册，得到一个"答得准、每句有出处、不知道就说不知道"的内部 AI 助手。

核心价值：
- **答案可追溯**：回答附带文档名与片段引用，避免大模型幻觉；
- **知识可更新**：增删文档即可更新知识，无需重新训练；
- **诚实拒答**：知识库无依据时明确拒答，不编造；
- **可评测**：内置评测，量化"答得准不准"。

## 2. 角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 游客 | 未登录 | 仅登录 / 注册页面 |
| 普通用户 | 登录后 | 上传文档、提问、查看评测 |

> V1 为**单租户基础认证**，不实现 RBAC、组织架构、多租户。

## 3. 核心场景

- S1 上传企业制度文档 → 自动解析、切分、向量化入库；
- S2 员工自然语言提问 → Router 分发（Chat / RAG / Agent）→ 返回带引用回答；
- S3 知识库无相关内容 → 诚实拒答；
- S4 运行评测 → 输出关键词命中率 / 来源准确率 / 拒答正确率 / 综合准确率；
- S5 多轮追问 → 结合上下文理解指代。

## 4. 功能需求（按优先级）

### P0（V1 必做）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 认证 | 注册 / 登录（JWT + PBKDF2），业务接口 Bearer 鉴权 |
| F2 | 文档 | PDF / Markdown / TXT 上传、解析、切分、向量化、列表、删除 |
| F3 | 问答 | Router 分发；RAG 检索增强；Agent（ReAct + 工具调用）；引用来源；拒答 |
| F4 | 评测 | 测试集评测，输出四类指标 |
| F5 | 数据 | MySQL 持久化（用户 / 文档 / 会话 / 消息 / 评测） |
| F6 | 工具 | knowledge_search（知识库检索）、calculator（AST 安全计算） |

### P1（V1 已完成）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F7 | DOCX | 解析 .docx（含表格文本） |
| F8 | 多轮对话 | chat / rag / agent 统一接入历史上下文 |
| F9 | 评测可视化 | 评测历史保存 + 查询 + 前端展示 |
| F10 | Rerank | 可配置重排模型，A/B 评测决定是否启用 |

### V2 backlog（本期不做）
OCR · Excel · 流式输出 · MCP · 多租户 · RBAC

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 安全 | JWT 鉴权、PBKDF2 密码哈希、密钥仅存 .env（gitignore）、参数校验 |
| 可测试 | 提供 hash / memory / fake 回退组件，无外网无模型也能跑通链路 |
| 可维护 | 分层架构、统一异常、日志 |
| 可扩展 | Embedding / VectorStore / LLM 均可替换（接口抽象） |
| 诚实性 | 所有指标来自真实评测，不预设、不编造 |
